# v3.12 조작·맵·광기 AI

## 이동과 방어

- A/D는 화면 좌우 이동. 상대 반대 방향을 누르면 가드합니다.
- 뒤를 두 번(← N ←) 입력하면 약 12F 백대시. 기본 속도는 5.4이며 캐릭터별 배율을 곱합니다. 뒤를 유지하면 가드도 됩니다.
- W/S를 **9F(약 0.15초)보다 짧게 눌렀다 떼면** 해당 방향으로 한 걸음 횡신합니다. 같은 방향을 연속으로 짧게 눌러도 한 걸음씩 이동합니다.
- 한 번 누르고 **9F 이상 유지**하면 W는 점프, S는 앉기입니다. 공격 커맨드의 ↓/↘는 유지 시간을 기다리지 않고 즉시 접수합니다. Shift 앉기와 Q/E 횡보도 보조 조작으로 유지됩니다.
- 같은 방향을 0.3초 안에 다시 누른 뒤 유지하면 앉기/점프 대신 횡보합니다. W/S를 떼면 멈춥니다. 방향 커맨드+공격을 입력한 경우 횡보로 오인하지 않도록 소비합니다.
- 잡기(U+I)는 기존보다 사거리가 0.55 늘었습니다. 상단·앉기·공중 판정과 가드 무시 규칙은 유지합니다.
- 하단 기상각은 가드 -19F입니다. 앉아서 막고 방향을 떼며 I를 누르면 **15F 기상 띄우기**로 사거리 안에서 확정 반격할 수 있습니다. 캐릭터별 기본 어퍼와 기상 띄우기는 다른 기술입니다.

## 횡 추적과 새 기술

전 캐릭터에 서로 다른 이름·모션·피해·발동의 **고유기**, **양방향 호밍기**, **공중 콤보 중 공참각 후 U 파생기**를 추가했습니다. KAI 등은 45개, REN/SHIN은 저스트 파생기 포함 46개입니다.

- 고유기: `↓ N → + I`. REN/SHIN은 정확한 저스트 입력이면 강화판이 나갑니다.
- 호밍기: `← N → + K`. ◉ HOMING 표시가 있으며 준비부터 활성 프레임까지 양쪽 횡을 따라갑니다. 거리를 벌리거나 가드로 대응하세요.
- 일반 기술은 직선/시계 방향 추적/반시계 방향 추적으로 나뉩니다. 방향 추적은 준비 중 일부까지만 회전하고 마지막 6F는 축을 고정합니다. 게임 내 기술표에 추적 방향을 표시합니다.
- 넓은 장타류는 짧은 횡신을 포착하지만 충분히 오래 도는 횡보에는 빗나갑니다. 빠른 횡신과 횡보의 회피 결과가 모든 기술에서 같지는 않습니다.
- 전체적인 공격 전진성은 기존보다 높였습니다. 상대를 뚫고 전진하지 않도록 거리를 제한합니다.
- 상대를 띄운 **콤보 중** 공참각을 쓰면 도약 뒤 지상 공격 전환을 정식 파생으로 허용합니다. 적중 뒤 U는 캐릭터별 착지 기술입니다. 일반 지상 공참각 이후 공중에 남아 있으면 다음 버튼은 점프 공격으로 처리합니다.

## 저스트 입력

KAI 섬뢰권은 `→ N ↓ ↘ + I`에서 마지막 ↘와 I가 **같은 60Hz 입력 프레임**에 들어와야 발동합니다. 한 프레임 늦으면 승류권입니다. 최종 방향과 버튼을 같은 입력으로 묶기 위해 동일 상태의 빠른 키보드 이벤트를 합치되, 앞선 방향 순서는 보존합니다.

REN 홍염 섬각, SHIN 월섬 일격도 `↓ N → + I`의 마지막 →와 I를 같은 프레임에 맞추는 저스트입니다. 늦으면 각자의 일반 고유기가 나갑니다. 강화판은 피해·발동·가드 이득이 좋으며 반드시 띄우는 기술은 아닙니다.

## 자리와 맵

경기 위의 **자리**와 **맵**에서 설정합니다. 연습·아케이드는 캐릭터 확정 시 적용됩니다. 온라인은 방장이 방을 만들 때 자리를 선택하고, 참가자는 반대 자리를 사용합니다. 호스트 역할과 전투의 1P/2P 자리는 독립적입니다.

| 맵 | 구조 |
|---|---|
| SUNSET TERMINAL | 무한 / 노을 도시 |
| JADE FOREST | 무한 / 숲 |
| MOON DOJO | 벽 / 도장 / 중심부터 7 |
| IRON FOUNDRY | 벽 / 제철소 / 중심부터 8 |
| RANDOM | 위 네 맵에서 하나 선택 |

랜덤 결과는 경기 시작 시 한 번 정하고 온라인 양쪽에 같은 값을 전달합니다. 한 경기의 라운드 사이에는 맵을 유지합니다. 벽에서는 이동·횡보·밀려남·잡기 위치 교환 뒤에도 경기장 경계를 벗어나지 않습니다.

벽 근처에서 공중 타격하면 첫 벽 타격은 **+6**, 두 번째는 **+3** 보너스 피해입니다. 세 번째 벽 타격은 추가 보너스 없이 강제 낙하·다운시켜 다시 띄우지 못합니다. 바운드 1회 제한과 재바운드 강제 다운도 함께 적용됩니다. 다운 후 하단 압박은 가능하지만 벽에서 공중 무한 콤보로 이어지지 않습니다.

## 광기 난이도

쉬움·보통·어려움에 **광기**를 추가했습니다. 광기는 관찰 가능한 공격/회수와 최근 행동을 이용해 다음을 선택합니다.

- 가드 후 확정 반격, 하단 가드 후 기상 띄우기
- 상대가 헛친 기술의 남은 회수·거리 안에서 어퍼
- 오래 가드하는 상대에게 잡기, 앉는 상대에게 중단, 하단 습관에 대한 예측 가드
- 기존 커맨드 기술 대부분과 신규 고유기·호밍기·저스트를 포함한 기술 선택
- 실제 60Hz 전투 시뮬레이션으로 생성한 피해 순위 콤보 루트. 무한 맵과 벽 맵의 경로를 분리하고 상황이 어긋나면 다른 후속기로 전환

콤보 검색은 **깊이 7, 빔 너비 8**로 빌드 시간을 제한합니다. 각 단계에서 실제 입력·거리·히트스톱·낙하·가드·벽 판정으로 후보를 비교합니다. 저장된 후보 중 피해가 가장 높은 경로를 우선하지만, 연속적인 이동 타이밍까지 포함한 모든 가능한 입력의 전역 최대 피해를 보장하는 탐색은 아닙니다. `npm run docs:combos`로 전투 수치 변경 후 다시 계산합니다. 결과는 `src/combo-routes.json`입니다.

프로토콜 14를 사용하므로 게임 양쪽과 매칭 호스트/AXIS SERVER를 모두 v3.12로 교체하세요.
