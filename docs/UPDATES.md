# EXE 업데이트 확인과 새 버전 게시

v3.8부터는 검증된 새 EXE를 자동 실행하고 이전 프로세스의 종료를 기다려 이전 AXIS 파일을 삭제합니다. 기존 v3.6/v3.7은 다운로드까지만 지원하므로 이번 v3.8은 한 번 직접 실행해야 합니다.

Windows v3.6 이상은 시작할 때 GitHub의 `downloads/latest.json`을 HTTPS로 읽고 현재 버전과 숫자로 비교합니다. 새 버전일 때만 콘솔에 다음을 표시합니다.

```text
새 버전: 3.9.0
다운로드 하시겠습니까?[y/n]
```

y + Enter는 다운로드, n + Enter는 현재 게임 계속입니다. 인터넷 연결 실패·메타데이터 오류·입력 종료 시 현재 게임을 계속 실행합니다. 확인 요청은 최대 6초, 다운로드는 최대 2분입니다. 잘못된 응답은 y/n을 다시 묻습니다. `--no-update` 옵션으로 확인을 건너뛸 수 있습니다.

다운로드한 EXE는 기존 EXE 옆에 `AXIS-v3.9.0-Windows-x64.exe`처럼 저장합니다. 임시 파일로 받은 뒤 SHA-256을 확인해야 최종 파일을 만듭니다. 64MiB를 넘거나 검증에 실패한 파일은 남기지 않습니다. 같은 이름의 파일은 체크섬이 같을 때만 재사용하며 다르면 덮어쓰지 않습니다. 쓰기 권한이 있는 일반 다운로드 폴더에서 실행하세요. v3.8 이상에서는 다운로드 후 새 EXE를 실행하고 현재 프로세스는 종료합니다. 새 프로세스는 이전 프로세스가 끝나기를 최대 15초 기다려 이전 파일을 삭제합니다. 같은 폴더의 다른 AXIS 실행 파일만 정리하며 자기 자신이나 일반 문서는 지우지 않습니다. 실행 실패·기다리기 실패·삭제 실패 시 콘솔에서 사유를 확인하세요. 파일 이름은 AXIS-Windows-x64.exe 또는 AXIS-v버전-Windows-x64.exe 형식을 유지하세요. 다른 이름으로 바꾸면 자동 전환 대신 수동 실행이 필요할 수 있습니다.

현재 다운로드 게시 파일이 교체되는 순간과 확인이 겹치면 체크섬이 맞지 않아 실패할 수 있습니다. 이후 다시 실행하세요. 버전 정보와 EXE는 같은 GitHub 저장소의 고정 경로만 사용하며 업데이트 서버 주소를 입력할 필요가 없습니다.

## 개발자가 새 버전을 게시하는 순서

1. 소스를 수정하고 테스트합니다. `npm version patch --no-git-tag-version` 등으로 `package.json`과 잠금 파일의 버전을 올립니다. 감지는 `숫자.숫자.숫자` 형식만 지원합니다.
2. `npm test`, `npm run docs:frames`, `npm run package:windows`를 실행합니다. 빌드가 `package.json` 버전을 EXE에 주입하고, 그 EXE의 체크섬으로 `release/latest.json`을 생성합니다.
3. 아래 **세 파일**을 `release/`에서 `downloads/`로 복사합니다.

   ```text
   AXIS-Windows-x64.exe
   AXIS-Windows-x64.exe.sha256
   latest.json
   ```

4. 소스·버전 변경·세 게시 파일을 함께 GitHub `main`에 커밋합니다. GitHub 웹 업로드라면 세 파일을 한 번에 업로드해 같은 커밋으로 게시하세요. EXE는 그대로 두고 버전 정보만 올리면 체크섬 오류나 잘못된 버전 안내가 발생합니다.
5. 원격 EXE의 SHA-256과 `latest.json`의 `sha256`이 같은지 확인하세요. 이전 버전 EXE를 실행해 y/n 안내와 다운로드를 확인합니다. 동일 버전에서는 묻지 않습니다.

`latest.json` 예시(체크섬은 빌드에서 자동 생성):

```json
{
  "version": "3.9.0",
  "sha256": "빌드된 EXE의 64자리 SHA-256"
}
```

Go 런처만 직접 빌드하는 개발자는 `-ldflags="-X main.currentVersion=버전"`을 지정해야 합니다. 일반 배포는 버전을 자동 주입하는 `npm run package:windows`를 사용하세요.

v3.5 이하에는 이 기능이 없으므로 v3.6을 처음 한 번 수동으로 받아야 합니다. 이 버전은 공중 콤보 판정도 바뀌었으므로 온라인 플레이어 둘과 매칭 호스트 모두 최신 파일로 바꿔야 합니다.
