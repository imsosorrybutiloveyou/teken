# AXIS ADVANCE v3.17 캐릭터별 커맨드·프레임표

60 FPS 기준입니다. S=발동, A=지속, R=회수, G=가드 시 공격자 유불리, H=지상 적중 시 공격자 유불리. L은 띄우기, B는 공중에서 맞혔을 때 콤보당 1회 바운드, KD는 다운입니다. 벽꽝 표기 기술은 벽 앞에서 지상/공중 적중 시 콤보당 1회 반동 띄우기(바닥 바운드와 별개), 재벽꽝은 강제 다운입니다. 저스트 [1F]는 마지막 방향과 공격을 같은 60Hz 입력 프레임에 맞춰야 하며 늦으면 KAI는 일반 승류권, REN/SHIN은 일반 고유기입니다. 재바운드는 강제 다운이며, 공중 내려찍기도 바운드입니다. 누운 상태 W 즉시 기상/J 하단 기상각(-19F)/K 중단 기상각(-15F)/뒤 입력 후방 기상. 하단은 누운 상대를 때립니다. 발동 S는 커맨드를 마친 공격 입력 이후 기준입니다. 잡기의 G는 적용되지 않습니다. 명시된 유불리는 최초 활성 프레임에 맞고 연계 취소를 하지 않았을 때 기준이며 공중·거리·늦은 활성 프레임 적중에 따라 달라집니다. 히트스톱은 양쪽에 동일하게 적용합니다.

→/←는 상대 기준 전진/후퇴, ↓/↑는 S/W, N은 중립(방향키 떼기)입니다. +는 동시 입력, ›는 연속 입력입니다. 프레임은 실제 전투 로직과 같은 src/characters.js에서 생성합니다.
