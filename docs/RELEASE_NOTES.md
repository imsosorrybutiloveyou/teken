# AXIS ADVANCE v3.16.0

- **달리기 공격:** 곰 BORU와 기계 ATLAS를 제외한 7명은 달리면서 U/I로 공중 손 공격, J/K로 도약 발차기를 씁니다. 실제로 도약하며 전진합니다.
- **몸통박치기:** BORU는 `산맥 붕진`, ATLAS는 `브레이크리스 차지`를 달리기 중 U+I로 씁니다. 점프하지 않고 몸통으로 밀어 넘어뜨립니다. 벽 앞에서는 벽꽝, 가드되면 -16F입니다. 양손 입력이 입력 프레임 경계에 걸려도 접수합니다.
- **→→→ 입력:** 전진·중립·전진·중립·전진을 약 0.55초 안에 입력하면 즉시 달립니다. 마지막 방향과 공격을 함께 입력하거나 마지막 방향을 뗀 뒤 0.15초 이내에 공격해 달리기 공격을 낼 수 있습니다. 기존 `→ N →`의 두 번째 전진을 0.3초 유지하는 달리기도 유지합니다. 전진 유지로 계속 달리며 방향을 떼면 멈춥니다. 방향은 상대 기준이므로 2P는 A/D가 반대입니다.
- **달리기 팔 자세:** 손만 앞뒤로 옮기던 방식 대신 어깨→굽힌 팔꿈치→손목이 함께 흔들리게 했습니다. 주먹 방향과 커스텀 스킨의 손도 전완 방향에 맞춥니다. 관절 길이·무릎 방향은 유지합니다.
- **큰 기 게이지:** 경기 아래 양쪽에 별도 패널로 표시합니다. 굵은 두 칸, 큰 숫자, 높은 대비와 1칸 이상 충전 시 테두리 발광을 추가했습니다. 모바일에서도 각 칸과 수치가 보입니다.
- **RAON 전면 재구성:** KAI 기술 복사를 제거하고 독립 데이터로 작성했습니다. 오른손 시작 I › U › J, 원형 장법·낮은 발 견제·뒤축 띄우기·회전축·양손 기둥형 강화기입니다. 대기 자세, 손·발 궤적, 준비/회수, 효과, 외형도 바꿨습니다. 기본 U는 10F입니다.
- RAON은 푸른 도포·밝은 바지·상투와 머리띠를 쓰는 환류 기공권 캐릭터입니다. 최대 2칸, 적중 +1/20칸·피격 +1/80칸, 기공탄·기 소비 콤보 연장은 유지합니다. 새 대전에서 0, 같은 대전의 다음 라운드에는 기를 유지합니다.

## 캐릭터별 달리기 기술

| 캐릭터 | 손 U/I | 발 J/K 또는 양손 U+I |
|---|---|---|
| KAI | 청류 낙풍장 | 청류 비상각 · J/K |
| REN | 적풍 다이브 엘보 | 홍염 플라잉 힐 · J/K |
| MIRA | 팔괘 공중쌍장 | 유수 비연각 · J/K |
| GORO | 태산 낙진권 | 거암 비상축 · J/K |
| HANA | 학익 비상수도 | 백학 비천축 · J/K |
| SHIN | 낙월 비검격 | 월영 도약축 · J/K |
| RAON | 유성 환공장 | 잔화 나선축 · J/K |
| BORU | — | 산맥 붕진 · U+I |
| ATLAS | — | 브레이크리스 차지 · U+I |

손 공격은 기본 18F·가드 +1F, 도약 발차기는 20F·가드 +3F입니다. 몸통박치기는 22F·가드 -16F입니다. 자세한 지속·회수·사거리는 게임의 기술표(H)를 보세요. 달리기 도약 공격은 선형이므로 횡이동을 읽고 사용하세요. 보통 전진 중 공격은 달리기가 성립하지 않았으면 원래 기술입니다.

## RAON 새 주요 커맨드

방향은 상대 기준, N은 방향키 떼기입니다. ↓=S, ↑=W, U/I/J/K=왼손/오른손/왼발/오른발입니다.

| 기술 | 커맨드 | 효과 |
|---|---|---|
| 월륜 뒤축 | ↘ + J | 뒤축 차기로 띄우기 · 16F |
| 낙화 쌍수 | ↓ + J | 공중 바운드 |
| 여명 기공탄 | ↓ ↘ → + U | 직선 중단 장풍 · 양 횡으로 회피 |
| 연엽 쌍장 → 연엽 회신각 | ← N → + U › K | 양손 장법 뒤 회전 발 파생 |
| 쐐기 하단각 → 엇발 섬각 | ↓ ↙ ← + K › U | 하단에서 중단 발차기로 연결 |
| 역상 회전각 | → N ← ↘ + J | 회전 도약 띄우기 |
| 진공 원무장 | ↓ N ← + I | 넓은 양손 장법·다운 |
| 폭련 기둥 | U+I · 기 1칸 | 양손으로 기를 솟구치는 강화 띄우기 · 가드 -22F |
| 작열 기공탄 | ↓ ↘ → + U+I · 기 1칸 | 강화 장풍·공중 연장 |
| 축기 연환장 | J+K · 기 1칸 | 짧고 빠른 원형 장법·공중 연장 |
| 윤회 팔꺾기 | ← + U+I | 관절 잡기 |

기 소비 공중 기술은 높이·경직을 회복하지만 바닥 바운드·벽꽝 사용 횟수는 초기화하지 않습니다. 전체 커맨드/프레임은 게임의 기술표(H)와 [FRAME_DATA.md](https://github.com/imsosorrybutiloveyou/teken/blob/main/docs/FRAME_DATA.md)에서 확인하세요. 이미지 파일 직접 불러오기는 [CUSTOMIZATION.md](https://github.com/imsosorrybutiloveyou/teken/blob/main/docs/CUSTOMIZATION.md)를 참고하세요.

## 다운로드와 호환

GitHub Releases에 게임 `AXIS-Windows-x64.exe`, 서버 `AXIS-SERVER-Windows-x64.exe`, 두 체크섬과 latest.json을 함께 제공합니다. Windows 10/11 x64용이며 서버는 LAN 휴대폰 브라우저 접속을 지원합니다. 게임 양쪽·첫 매칭 호스트 또는 AXIS SERVER를 **v3.16**으로 맞추세요. 프로토콜은 **18**입니다. Windows 및 물리 휴대폰 직접 실행은 미검증이며 브라우저·모바일 에뮬레이션으로 검사합니다.

## 다음 버전 게시 절차

1. package.json/lock, desktop/update.go, 화면 버전과 필요한 호환 프로토콜을 갱신합니다. Node 매칭 서버 `server/lobby.js`와 Go 서버·클라이언트의 프로토콜을 함께 반영합니다.
2. `npm test`, 관련 브라우저 검사, `npm run docs:frames`를 실행합니다. 전투가 바뀌면 `npm run docs:combos` 후 루트를 재검증합니다.
3. Go 1.26+에서 `npm run package:windows`로 게임·서버를 함께 빌드합니다.
4. release의 두 EXE·두 체크섬·latest.json을 downloads에 복사하고 `npm run release:verify`를 실행합니다.
5. 소스/문서/서버/실행 파일을 모두 커밋하고 새 manifest를 main에 푸시하면 Actions가 v버전 Release에 두 실행 파일을 게시합니다. 게시된 두 파일의 SHA-256과 작업 폴더가 깨끗한지 확인한 뒤 완료를 알립니다.
