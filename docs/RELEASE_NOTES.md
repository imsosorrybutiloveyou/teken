# AXIS ADVANCE v3.14.0

- **벽 시인성:** 두 벽 맵의 테두리를 밝고 굵게 표시하고, 1.7 높이의 난간과 기둥을 추가했습니다. 도장은 청백색, 제철소는 주황색입니다. 실제 충돌 경계와 같은 다각형을 사용합니다.
- **벽꽝:** 청류 돌파·청류 통발 등 전진 타격을 벽 앞에서 맞히면 상대가 벽에 부딪히고 안쪽으로 튀어 오릅니다. 지상 적중에서도 띄울 수 있고, 공중 콤보 중에도 사용할 수 있습니다.
- 벽 반동은 **콤보당 1회**입니다. 바닥 바운드 사용 횟수와 별개이며, 같은 콤보의 두 번째 벽꽝은 강제 다운입니다. 기존 세 번째 벽 타격의 강제 다운도 유지합니다. 가드·잡기·누운 상대 타격으로 벽 반동을 만들 수 없습니다.
- 각 캐릭터의 전진기·밀어차기에 벽꽝 성능을 추가했습니다. 게임의 **기술표(H)**와 [전체 커맨드·프레임표](https://github.com/imsosorrybutiloveyou/teken/blob/main/docs/FRAME_DATA.md)에 벽꽝 기술을 표시합니다.
- **GitHub Releases:** 게임 EXE와 AXIS SERVER EXE를 함께 게시합니다. 체크섬과 자동 업데이트용 `latest.json`도 첨부합니다.

## KAI 벽꽝 기술 예시

방향은 상대 기준이며 N은 방향키를 떼는 중립입니다.

| 기술 | 커맨드 |
|---|---|
| 청류 돌파 | → N → + I |
| 청류 통발 | → N → + U |
| 파룡 붕권 | ↓ N → + I |
| 청류 옆차기 | → + K |

상대를 벽 가까이 밀어둔 뒤 위 기술을 맞히고, 튀어 오를 때 잽이나 커맨드 기술로 이어가세요. 벽을 등진 상대가 약 0.65 이내에 있을 때 벽 반동이 발생합니다. 벽에서 멀거나 밀리는 방향에 벽이 없으면 원래 적중 효과가 나옵니다. 무한 맵에는 벽꽝이 없습니다. 새 콤보에서는 다시 사용할 수 있습니다.

## 다운로드

- `AXIS-Windows-x64.exe`: Windows 10/11 x64 게임. 더블클릭하면 브라우저가 열립니다.
- `AXIS-SERVER-Windows-x64.exe`: 같은 네트워크에서 PC·휴대폰이 주소로 접속하는 서버. 게임 EXE와 별도입니다.
- `.sha256`: 각 EXE의 SHA-256 체크섬입니다.

게임과 첫 매칭 호스트 또는 AXIS SERVER를 모두 **v3.14**로 맞추세요. 전투·매칭 프로토콜은 **16**입니다. 실제 Windows에서 직접 실행한 검증은 하지 않았습니다.

## 이후 버전 게시 방법

1. `package.json`, `package-lock.json`, `desktop/update.go`, 화면 버전·호환 프로토콜을 갱신하고 이 변경 설명서를 새 버전으로 수정합니다.
2. `npm test`, `npm run docs:frames`, 필요한 브라우저 검증을 실행합니다. 전투가 바뀌면 `npm run docs:combos`로 AI 콤보 데이터도 갱신합니다.
3. `npm run package:windows`로 게임과 서버를 함께 빌드합니다. Go 1.26 이상이 필요합니다.
4. `release/`의 두 EXE, 두 `.sha256`, `latest.json`을 `downloads/`에 복사하고 `npm run release:verify`로 검사합니다.
5. 변경 내용과 `downloads/latest.json`을 함께 `main`에 푸시하면 **Publish Windows game and server** Actions 워크플로가 `v버전` Release를 만들고 두 실행 파일을 모두 첨부합니다. GitHub Actions가 활성화되어 있어야 합니다. Actions에서 수동 재실행도 가능합니다.

다음 버전에도 서버 EXE를 생략하지 않습니다. 저장소 `downloads/`와 Releases에 동일한 체크섬의 파일을 게시합니다. 자동 업데이트의 기존 저장소 주소도 계속 제공합니다.
