# AXIS ADVANCE v3.15.0

- **콤보 밀어내기 증가:** 첫 공중 적중부터 약 25% 증가하고 후속 타수에 따른 밀기 증가도 강화했습니다. 거리가 멀어질 때 전진기를 연결하거나 추격해야 합니다.
- **딜레이 캐치 피해 감소:** 막힌 공격의 회수 중 확정 반격과 그 뒤 이어지는 동일 콤보의 피해에 ×0.85를 적용합니다. 반격 가능 프레임은 유지합니다.
- **달리기:** 상대 기준 `→ N →`로 대시한 뒤 두 번째 전진을 약 0.3초 유지하면 달립니다. 일반 전진 4.0 → 대시 5.6 → 달리기 7.0이며 캐릭터별 이동 배율이 적용됩니다. 방향을 떼거나 공격·앉기·횡이동·피격을 하면 달리기를 멈춥니다.
- **RAON 추가:** 기공권을 쓰는 9번째 오리지널 캐릭터. 선택 화면은 **9명 + 가운데 RANDOM = 10칸(2행×5열)**입니다. 랜덤은 확정할 때 실제 캐릭터로 정해져 온라인에도 같은 선택이 전송됩니다.
- **기 게이지:** 최대 2칸. 한 칸은 20포인트이며, 적중 1회에 +1포인트(1/20칸), 피격 1회에 +0.25포인트(1/80칸). 가드·헛침에는 차지 않고 기 소비 기술은 적중 시 기를 다시 얻지 않습니다. 새 대전에서는 0으로 시작하고 같은 대전의 다음 라운드에는 기를 유지합니다.
- **강화기·콤보 연장:** 한 칸을 써서 강화 기공탄·승룡격·연환장을 사용합니다. 공중 적중 시 높이와 경직을 회복해 콤보를 이어가며, 바닥 바운드·벽꽝 횟수 제한은 초기화하지 않습니다. 기가 부족하면 발동하지 않고 안내합니다.
- **직선 장풍:** 기공탄은 발사 때 방향으로 날아가는 실제 투사체입니다. 양쪽 횡신·횡보로 피할 수 있고 후퇴 가드로 막습니다.
- **이미지 변경:** 게임 안에서 파일을 골라 초상화·격자 스킨을 적용합니다. GitHub 계정·Fork·JSON 편집·EXE 재빌드가 필요 없습니다. [새 이미지 변경 안내](https://github.com/imsosorrybutiloveyou/teken/blob/main/docs/CUSTOMIZATION.md)
- 아케이드는 자신을 제외한 **8명**과 대전합니다. 터치 화면에는 U+I, J+K 동시 입력 버튼도 추가했습니다.

## RAON 주요 기술

방향은 상대 기준입니다. ↓=S, →=전진(A 또는 D), N=방향키 떼기. U/I/J/K=왼손/오른손/왼발/오른발입니다.

| 기술 | 커맨드 | 기 | 효과 |
|---|---|---|---|
| 여명 기공탄 | ↓ ↘ → + U | 0 | 직선 중단 장풍, 양 횡 회피 |
| 작열 기공탄 | ↓ ↘ → + U+I | 1칸 | 빠르고 강한 장풍, 공중 콤보 연장 |
| 여명 승룡격 | U+I | 1칸 | 강화 띄우기, 가드 시 -22F |
| 축기 연환장 | J+K | 1칸 | 8F 공중 연장기, 높이·유지 시간 회복 |
| 잡기 | ← + U+I | 0 | RAON 전용 잡기 입력 |
| 천공 니 | ↗ + J | 0 | 도약 띄우기 |
| 여명 쇄권 | ← N → ↘ + I | 0 | 카운터 띄우기 |

초반에는 기본기·커맨드 기술로 기를 모으고, 띄우기 후 연환장을 연결해 추격하세요. 일반 장풍은 거리가 멀면 확정 반격을 당하기 어렵지만 준비/회수 동작에 접근당할 수 있습니다. 상세 수치는 게임의 **기술표(H)**와 [프레임표](https://github.com/imsosorrybutiloveyou/teken/blob/main/docs/FRAME_DATA.md)에서 확인하세요.

## 다운로드와 호환

GitHub Releases에 `AXIS-Windows-x64.exe`, `AXIS-SERVER-Windows-x64.exe`, 두 `.sha256`, `latest.json`을 함께 제공합니다. Windows 10/11 x64용이며 서버는 LAN의 휴대폰 접속을 지원합니다. 게임 양쪽·첫 매칭 호스트 또는 AXIS SERVER를 **v3.15**로 맞추세요. 프로토콜은 **17**입니다. 실제 Windows 및 물리 휴대폰 직접 실행은 미검증이며 브라우저·모바일 에뮬레이션으로 검사합니다.

## 다음 버전 게시 절차

1. package.json/lock, desktop/update.go, 화면 버전과 필요한 호환 프로토콜을 갱신하고 이 설명서를 수정합니다.
2. `npm test`, 관련 브라우저 검사, `npm run docs:frames`를 실행합니다. 전투가 바뀌면 `npm run docs:combos` 후 루트를 재검증합니다.
3. Go 1.26+에서 `npm run package:windows`로 게임·서버를 함께 빌드합니다.
4. release의 두 EXE·두 체크섬·latest.json을 downloads에 복사하고 `npm run release:verify`를 실행합니다.
5. 새 manifest를 main에 푸시하면 **Publish Windows game and server** Actions가 v버전 Release에 두 실행 파일을 게시합니다. 게시된 두 파일의 SHA-256을 확인한 뒤 배포 완료를 알립니다.
