# AXIS ADVANCE v3.17.0

## RAON 이동과 기 효과

- **다리 고정 수정:** RAON 고유 자세가 보행의 발 위치를 고정값으로 덮어쓰던 문제를 수정했습니다. 전진·후퇴·달리기에서 발과 무릎이 번갈아 움직입니다. 기존 관절 길이와 무릎 굽힘 방향은 유지합니다.
- **기공파:** 발사 전 손 앞 충전 구체, 날아가는 구체의 다중 고리·회전 입자·잔광 꼬리, 기공파 타격 효과를 추가했습니다. 일반은 청록색, 강화는 푸른색입니다.
- **기 소비 기술:** 폭련 기둥·작열 기공탄·축기 연환장을 사용할 때 몸 주위의 푸른 오라, 바닥 고리, 위로 솟는 번개와 입자를 표시합니다. 적중 시에도 푸른 타격 효과가 나옵니다. 원격 상대 화면에서도 같은 기술 상태로 표시합니다.
- **피해 조정:** 일반 여명 기공탄은 16→11, 강화 작열 기공탄은 26→20입니다. 강화는 여전히 기 1칸을 쓰며 공중 연장 효과가 있습니다. 두 장풍 모두 양쪽 횡으로 회피할 수 있습니다.

| RAON 기술 | 커맨드 | 기 | 기본 피해 |
|---|---|---|---|
| 여명 기공탄 | ↓ ↘ → + U | 없음 | 11 |
| 작열 기공탄 | ↓ ↘ → + U+I | 1칸 | 20 |
| 폭련 기둥 | U+I | 1칸 | 28 |
| 축기 연환장 | J+K | 1칸 | 12 |

방향은 상대 기준이며, 피해에는 기존 콤보·딜레이 캐치 보정이 적용됩니다. 최대 기 2칸, 적중 1/20칸·피격 1/80칸 축적은 같습니다. 강화기 적중은 기를 돌려주지 않습니다. 모든 기술과 프레임은 게임의 **기술표(H)** 또는 [FRAME_DATA.md](FRAME_DATA.md)에서 확인하세요.

## 광기 AI

- **벽 판단:** 상대 뒤의 실제 맵 경계를 확인해 벽꽝 가능한 전진 장법·돌진·밀어차기를 사용하고 튀어나온 상대에게 후속 콤보를 넣습니다. 콤보당 벽 반동 1회, 재벽꽝·벽 타수 제한을 초기화하지 않습니다.
- **달리기 압박:** 사거리에 맞춰 실제 → N → N → 입력으로 공참각류·공중 손 공격을 사용합니다. BORU/ATLAS는 U+I 몸통박치기입니다. 더 먼 거리는 먼저 달려서 접근합니다.
- **콤보 추격:** 멀어지는 공중 상대는 도약 발차기로 추격하고, 공중 콤보 중 달리기 발차기의 착지 파생을 사용합니다.
- **기 운용:** RAON은 거리·측면 이동·보유 기에 따라 일반/강화 장풍을 선택합니다. 공중 타수가 쌓이고 사거리·높이가 맞으면 기 1칸으로 콤보를 연장합니다. 가까이서는 상대 공격·남은 체력을 보고 강화기를 선택합니다. 기를 공짜로 부여하거나 음수로 만들지 않습니다.
- **헛침 반격 수정:** 공격 판정이 끝난 회수 구간까지 계속 방어하던 로직을 수정해 실제 헛친 큰 기술을 어퍼로 반격합니다. 기존 하단 방어·기상 어퍼, 잡기 심리, 호밍기 판단과 피해 순으로 생성된 콤보 루트를 유지합니다.
- 다운 후 기상할 때 남아 있던 오래된 입력 계획은 취소합니다.

## 게시 절차

버전과 호환 프로토콜을 Node 서버·Go 서버·클라이언트에서 함께 갱신합니다. `npm run docs:combos`, `npm run docs:frames`, `npm test`와 관련 브라우저 검사를 실행합니다. Go 1.26+에서 `npm run package:windows`로 두 EXE를 빌드하고 두 체크섬·latest.json과 함께 downloads에 복사한 뒤 `npm run release:verify`를 실행합니다. 서버 소스를 포함한 모든 변경과 새 manifest를 main에 푸시하면 Actions가 Release를 게시합니다. 게시된 두 EXE·두 체크섬·manifest가 저장소의 파일과 같은지 확인한 뒤 완료를 알립니다.
