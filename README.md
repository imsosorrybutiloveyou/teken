# AXIS ADVANCE — Pixel Fighting v2

휴대용 격투 게임 감성의 **2D 픽셀 캐릭터 + 3D 좌표 이동** 게임입니다. Canvas 2D로 픽셀 그래픽을 그리며, 실제 전투는 좌우·깊이·공중 좌표로 판정합니다. 캐릭터와 배경은 직접 만든 오리지널 그래픽입니다.

## Windows에서 바로 실행

[**Windows EXE 다운로드 — AXIS-Windows-x64.exe**](https://github.com/imsosorrybutiloveyou/teken/raw/refs/heads/main/downloads/AXIS-Windows-x64.exe)

Windows 10/11 64비트용입니다. EXE를 더블클릭하면 기본 브라우저에서 게임이 열립니다. Node.js 설치나 압축 해제가 필요하지 않습니다. 함께 열린 실행 창은 게임 중 유지하고 종료할 때 닫으세요. 실제 Windows에서의 직접 실행 검증은 아직 하지 않았습니다. [전체 사용 설명서](사용설명서.md) / [SHA-256](downloads/AXIS-Windows-x64.exe.sha256)

## v2 변경 사항

- 3D 폴리곤 캐릭터 대신 **2D 픽셀 캐릭터와 원근감 있는 무한 경기장**
- **U 왼손 / I 오른손 / J 왼발 / K 오른발** 독립 기본기
- 방향 입력 이력에 따른 커맨드 기술 17종(연계기 포함)
- 좌우 이동 3.0 → **5.1**, 횡이동 **5.7**, 앞 방향 두 번 입력 시 **8.8** 속도의 대시
- 벽·링 경계·좌표 래핑 없는 무한 맵과 추적 카메라
- 화면에 최근 방향 입력, 현재 기술 이름, 세계 좌표 표시
- CPU 연습전과 WebRTC P2P 온라인 대전 유지

현재 두 캐릭터는 외형이 다르고 기술 세트는 같습니다. 키보드가 필요하며 모바일 터치 조작은 포함하지 않습니다.

## 키와 커맨드

| 키                  | 조작                                        |
| ------------------- | ------------------------------------------- |
| A / D (또는 ←/→ 키) | 좌우 이동. 상대 쪽이 전진                   |
| W / S (또는 ↑/↓ 키) | 경기장 깊이 방향 횡이동. 커맨드에서는 ↑ / ↓ |
| U                   | 왼손 LP                                     |
| I                   | 오른손 RP                                   |
| J                   | 왼발 LK                                     |
| K                   | 오른발 RK                                   |
| U + I               | 양손 동시 입력: 잡기                        |
| J + K               | 양발 동시 입력: 하단 스윕                   |
| L                   | 서서 가드                                   |
| Shift               | 앉기: 상단 회피                             |
| Shift + L           | 앉아서 가드: 하단 방어                      |
| 전진, 떼기, 전진    | 대시                                        |
| Esc                 | 연습전 일시정지 / 계속하기                  |

**→/←는 상대 기준 전진/후퇴**입니다. P1이 왼쪽에 있다면 →=D, ←=A이며, P2가 오른쪽에 있다면 반대입니다. ↓=S, ↑=W, ↘=전진+S입니다. 방향 커맨드는 **0.7초 이내**에 순서대로 입력하고 마지막 방향에서 공격 버튼을 누르세요. 동시 입력은 `+`, 연속 입력은 `›`로 표시합니다.

| 입력           | 기술              | 종류           |
| -------------- | ----------------- | -------------- |
| U              | 왼손 잽           | 상단           |
| I              | 오른손 스트레이트 | 중단           |
| J              | 왼발 프런트 킥    | 중단           |
| K              | 오른발 라운드 킥  | 중단           |
| U › I › K      | 원 투 스핀 피니시 | 기본 연계기    |
| ↘ + I          | 라이징 어퍼       | 띄우기         |
| ↓ + J          | 로우 킥           | 하단           |
| ↓ ↘ → + I      | 썬더 스트라이크   | 전진 중단 강타 |
| → ↓ ↘ + I      | 드래곤 어퍼       | 띄우기         |
| ↓ ↘ → + K      | 토네이도 킥       | 중단 회전 킥   |
| →, 떼기, → + I | 대시 임팩트       | 돌진 중단      |
| ← → + U        | 브레이크 팜       | 중단 장타      |
| ← + K          | 백 스핀 킥        | 중단           |
| ↑ + J          | 점핑 니           | 띄우기         |
| U + I          | 숄더 브레이크     | 잡기           |
| J + K          | 더블 스윕         | 하단           |

공중 콤보 예: **↘+I › U › I › K**. 상대와 가까운 거리에서 현재 공격이 나가는 중 다음 공격을 하나씩 입력하세요. 입력 버퍼는 하나이므로 모든 키를 한꺼번에 누르면 중간 입력이 덮어써질 수 있습니다. 가드하거나 헛친 공격은 연속 적중하지 않습니다.

## 소스로 실행

Node.js 22.12 이상(검증: 24), 최신 데스크톱 Chrome/Edge/Firefox가 필요합니다.

```sh
npm ci
npm run dev
```

터미널의 `Local:` 주소를 같은 PC의 브라우저에서 여세요. 기본 포트는 5173입니다. 클라우드의 localhost와 내 PC의 localhost는 서로 다릅니다. `npm run build`로 생성한 `dist/` 전체를 HTTPS 정적 호스팅의 도메인 루트에 배포할 수도 있습니다. 공개 웹사이트 배포는 수행하지 않았습니다.

## 온라인 대전

두 사람 모두 **v2** 게임을 각각 열어야 합니다. 이전 v1 실행 파일과는 연결 코드가 호환되지 않습니다. `AXIS2.`로 시작하는 최신 코드를 사용하세요.

1. 방장: **온라인 대전 → 방 만들기 → 초대 코드 생성**, 전체 코드를 상대에게 전송.
2. 참가자: **초대받아 참가**, 받은 코드 입력 후 **응답 코드 생성**, 응답을 방장에게 전송.
3. 방장: 응답 코드 입력 후 **응답 적용 · 연결**.

방장은 P1 KAI, 참가자는 P2 REN입니다. 실제 게임 데이터는 WebRTC DataChannel로 전송합니다. 호스트가 60Hz로 판정하고 참가자에게 20Hz 스냅샷을 보냅니다. 커맨드 판정도 호스트가 입력 이력을 읽어 처리합니다. 온라인 일시정지는 비활성화되고 새 대전 시작은 호스트가 담당합니다.

Google STUN(`stun.l.google.com:19302`)을 사용하며 TURN 중계 서버는 없습니다. 일부 대칭 NAT·회사/학교 방화벽에서는 연결이 불가능할 수 있습니다. 롤백 넷코드는 없으며 참가자는 왕복 지연의 영향을 받습니다. 연결이 끊기면 새 코드를 만들어 다시 연결하세요.

## 검증과 EXE 빌드

```sh
npm test                 # 4버튼, 커맨드/미러링/시간 제한, 콤보, 가드, 대시, 무한 좌표, 네트워크 입력 검증
npm run build
npx playwright install chromium
npm run dev              # 별도 터미널
npm run test:browser     # 실제 브라우저 두 개로 P2P 및 물리 키 입력 검증
```

브라우저 테스트는 픽셀 화면, 이동, 기술표, 일시정지, 실제 P2P 연결, 원격 공격 피해, P2 커맨드와 동시 입력, 구 경기장 경계를 넘은 좌표 동기화, 연결 종료, 모바일 배치를 확인합니다. `CHROMIUM_PATH`와 `TEST_BASE_URL`로 브라우저 실행 파일과 서버 주소를 지정할 수 있습니다.

EXE는 Go 1.26 이상의 표준 라이브러리만으로 패키징합니다.

```sh
npm ci
npm run package:windows
```

`GO_BINARY`로 Go 실행 파일 경로를 지정할 수 있습니다. `release/`에 생성된 EXE와 `.sha256` 파일을 함께 `downloads/`에 복사해 커밋하면 배포 파일이 갱신됩니다. 런처는 게임·글꼴을 내장하고 `127.0.0.1`의 임의 포트에서만 서버를 엽니다. 런타임에 Node.js나 Go를 설치할 필요가 없습니다.

코드: `src/combat.js` 입력 이력·커맨드·전투, `src/scene.js` 픽셀 렌더러·원근 투영·스프라이트 애니메이션, `src/network.js` P2P 연결·검증, `src/input.js` 키 이벤트·온라인 입력 큐, `src/main.js` HUD·게임 루프. 글꼴의 SIL Open Font License는 `public/fonts/`에 있습니다.
