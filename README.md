# AXIS ADVANCE v3.14

2D 픽셀 캐릭터로 싸우면서 상대를 중심으로 횡이동하는 격투 게임입니다. 카메라는 두 격투가가 화면 양쪽에 있는 대치 구도를 유지합니다. 모든 그래픽은 직접 만든 오리지널 캐릭터·배경입니다.

[**Windows EXE 다운로드**](https://github.com/imsosorrybutiloveyou/teken/raw/refs/heads/main/downloads/AXIS-Windows-x64.exe) · [사용 설명서](사용설명서.md) · [캐릭터별 커맨드·프레임표](docs/FRAME_DATA.md) · [공용 서버 배포 설명서](docs/DEPLOYMENT.md)

Windows 10/11 64비트용입니다. EXE를 더블클릭하면 기본 브라우저에서 열리고, Node.js 설치가 필요 없습니다. 함께 열린 실행 창은 게임 중 유지하세요. 제작자 인증서로 서명되지 않았으며 실제 Windows에서의 직접 실행 검증은 아직 하지 않았습니다. [SHA-256](downloads/AXIS-Windows-x64.exe.sha256)

**EXE를 먼저 실행한 PC가 매칭 호스트가 됩니다.** 같은 LAN의 다음 EXE는 자동 검색으로 그 PC에 연결합니다. 인터넷 친구는 첫 PC의 공개 접속 주소를 입력해야 합니다. TCP 8787 접근을 허용하고 공유기 사용 시 포트 전달 또는 서로 연결되는 VPN이 필요합니다. 전투는 WebRTC P2P입니다. [접속 방법](사용설명서.md#6-온라인-준비-첫-pc가-호스트)

## 조작

| 키                    | 동작                                             |
| --------------------- | ------------------------------------------------ |
| A / D 또는 방향키 ←/→ | 화면 좌우 이동. 상대 반대쪽으로 누르면 후퇴 가드 |
| W / S 또는 방향키 ↑/↓ | S 앉기 · W 점프 · Q/E 유지 횡보                  |
| U / I                 | 왼손 LP / 오른손 RP                              |
| J / K                 | 왼발 LK / 오른발 RK                              |
| U + I / J + K         | 양손 잡기 / 하단 스윕                            |
| Shift                 | 앉기, 상단 회피                                  |
| 후퇴 + Shift 또는 ↙   | 하단 가드. 중단에는 취약                         |
| 전진-떼기-전진        | 대시                                             |
| Esc                   | CPU 연습 일시정지 / 계속                         |

→/← 커맨드는 **상대 기준**입니다. P1의 전진은 D, P2의 전진은 A입니다. ↓=S, ↑=W, ↘=전진+S. 방향 커맨드는 0.85초 이내에 입력하고 마지막 방향에서 공격 버튼을 누르세요. `+`는 동시 입력, `›`는 차례로 입력입니다. N은 방향키를 떼는 중립입니다. 키보드 물리 위치를 읽으므로 한글 입력 중에도 사용할 수 있습니다.

## 개발·로컬 서버 실행

Node.js 22.12 이상(검증: 24), 최신 Chrome/Edge/Firefox와 키보드가 필요합니다.

```sh
npm ci
npm run dev
```

Vite 개발 서버에도 매칭 API를 포함합니다. 터미널의 실제 주소로 두 브라우저를 열면 방 생성과 입장을 시험할 수 있습니다. 기본 포트는 5173입니다.

운영 구성으로 실행:

```sh
npm run build
npm start
```

기본 포트 8787에서 웹 게임·매칭 API·SSE를 함께 제공합니다. `PORT`로 변경할 수 있습니다. 공용 배포는 HTTPS가 필요합니다. GitHub 파일 업로드나 정적 Pages 배포만으로는 매칭 서버가 운영되지 않습니다.

## 검증·EXE 빌드

```sh
npm test
npm run build
npm start                    # 별도 터미널에서 운영 서버 실행
npx playwright install chromium
npm run test:browser
npm run test:assets
npm run test:rig
npm run test:advanced
npm run docs:frames
```

브라우저 테스트는 실제 두 클라이언트로 퀵 매치 제거, 방 목록과 선택 입장, 매칭 전 선택 금지, 양쪽 선택 확정, 자동 WebRTC 연결, MIRA/GORO와 KAI/REN 대전, 회전 중 양쪽 구도, 원격 피해, 실제 키보드 5타 공중 콤보·바운드 및 블러드 크로스 가드 후 확정 어퍼, 초풍·나락·통발·공참각 동기화, 연습 CPU/정지 샌드백·체력 자동 회복 전환과 모바일 배치를 확인합니다. `CHROMIUM_PATH`, `TEST_BASE_URL`, `TEST_GUEST_URL`, `TEST_AUTO_HOST`, `TEST_LOBBY_URL`을 지정할 수 있어 EXE에 내장된 파일과 별도 매칭 서버의 교차 출처 연결도 검증할 수 있습니다.

Go 1.26 이상을 설치한 개발자는 다음으로 EXE를 만듭니다.

```sh
npm run package:windows
```

`GO_BINARY`로 Go 경로를 지정할 수 있습니다. 결과 `release/`의 EXE·`.sha256`·`latest.json`을 함께 `downloads/`에 복사해 커밋합니다. 런처는 웹 게임을 루프백 임의 포트에서 제공하고, 기존 LAN 호스트가 없으면 TCP 8787 매칭 서버와 UDP 38787 검색 응답을 엽니다. `--host http://주소:8787`로 특정 호스트에 참가할 수 있습니다. 브라우저는 WebRTC 사용을 위해 항상 자신의 localhost 게임 주소를 사용합니다. 호스트 EXE 종료 시 로비 세션·방 목록은 소멸하며 자동 이전은 하지 않습니다. 새 호스트가 필요하면 나머지 EXE를 재실행하세요.

## 온라인 범위

서버는 방·캐릭터 선택·WebRTC 신호만 담당합니다. 게임 판정은 P1 호스트 60Hz, 참가자 스냅샷 30Hz이며 전투 데이터는 P2P로 흐릅니다. 롤백 넷코드와 TURN 중계는 포함하지 않아 참가자는 왕복 지연의 영향을 받고 일부 대칭 NAT·차단망에서는 연결이 실패할 수 있습니다. 방은 단일 서버의 메모리에 있으며 재시작하면 초기화됩니다.

코드 구성: `src/characters.js` 커맨드·프레임, `src/fighter-kits.js` 독립 기술, `src/style-motion.js` 스타일별 모션, `src/custom-assets.js` 에셋 교체, `src/combat.js` 판정·이동, `src/scene.js` 픽셀 렌더러·회전 투영, `src/input.js` 순서 보존 입력 큐, `src/lobby.js` 매칭 클라이언트, `src/network.js` WebRTC, `server/` 선택적 공용 매칭 서버, `desktop/` 내장 매칭 호스트·LAN 검색·런처. 글꼴 라이선스는 `public/fonts/`에 있습니다.
